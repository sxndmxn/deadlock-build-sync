How to use these choices

Choose an optional item only when you need its main effect. PICK ONE is a choice for the next purchase. An upgrade consumes a component. The preview accounts for required components, upgrade credits and inventory limits. Buying a detour delays the next core purchase; an upgrade consumes the named component.

These previews show one optional choice at a time. Recalculate from your current inventory before combining choices. The CLI can do that with a state file and checks spendable souls, item slots and the four active bindings. Ahead/behind does not yet select a validated purchase preference.

Evidence behind this preview

Identities come from the frozen discovery experiment. The pool uses first purchases among discovery core owners, including early items that may later be sold and late extensions. Each pool item has at least 20 buyers; each tier shows up to ten. Placement is observational. Item mechanics describe reasons to consider a choice; their conditional win-rate benefit has not been established. These source snapshots span balance changes. No Steam or production build was changed.
